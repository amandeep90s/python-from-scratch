# Python Tutorial

## Why Learn Python?

- Easy to read and write
- Large community and ecosystem
- Used in web development, data science, automation, machine learning, and cybersecurity
- Works on Windows, macOS, and Linux
- Great for learning programming fundamentals

## Quick Start

### Install Python

Download Python from the official website:

https://www.python.org/

### Verify installation

```bash
python --version
```

or:

```bash
python3 --version
```

### Run your first script

```python
print("Hello, World!")
```

Output:

```python
Hello, World!
```

## Basic Python Examples

### Variables

```python
name = "Alice"
age = 25
is_student = True

print(name)
print(age)
print(is_student)
```

### Arithmetic

```python
x = 10
y = 5

print(x + y)
print(x - y)
print(x * y)
print(x / y)
```

### If statement

```python
age = 18

if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")
```

### Loop

```python
for i in range(5):
    print(i)
```

### Function

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("John"))
```
